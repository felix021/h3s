    助听 · 每频段调节

    MPO 走 key30（L3 链，候选 UNTESTED）

    通透/辅听链（mic→DAC）的逐频段草稿：增益放大环境声，上限是该频段期望的最大 输出（数字域 dB，非标定 SPL）。固件为单带 WDRC，每频上限聚合为全带 MPO 生效 （见下方汇总行）。全带 MPO 经 BLE 自定义命令 0x30 写入固件 VM key 30 （8B 版本化协议），十段 EQ 增益/频点写 key 31（88B 版本化协议），均由候选固件 在下次开启辅听时应用（MPO 全带曲线 + EQ 十段逐条段消息，候选 UNTESTED）。 十个频段横排：每列上层数字是上限（点击弹窗修改），中间长条是该频段增益 （先点选锁定，再上下拖动；鼠标可直接拖，双击归零），最下是频点。

    全带 MPO（聚合生效值） 110 dB 全带生效（取十频段最小值，任一频段调低都会压低全带上限）；固件 Drc1Eff 为单带 WDRC，每频独立限幅需 multiband（未落地）。

    本地草稿，尚未发送。

    进入 ROM 模式

    一次性请求

    对已打开的普通 QCY 设备，先读取能力，再发送一次进入请求。 设备随后会重启并重新枚举。

    请求可能因设备重启报错。请重新扫描，以出现 BR28 ROM 身份为准， 不要重复发送进入请求。

    ROM 会话与读取

    不写 Flash 

    

      
    
        操作说明
        
    
          RAM loader 使用原生桥固定摘要校验，通过 FB06 装载、FB08 启动，
          再以 FC0A 确认 SPI NOR。此步骤会写 RAM 并执行 loader。
        
    
        
    
          ROM 窗使用 FD07，Flash 备份使用 FD05。两项均保留双读一致检查，
          成功后保存到应用私有目录；失败不自动重试。
          此页没有 Flash 擦除或编程入口。

    安全提示
    
        升级前必读
      
    
      
      
        
    • 升级中勿断开：传输期间保持手机与耳机的 BLE 连接，
          不要锁屏杀后台（升级以前台服务 + 唤醒锁运行）、不要把手机带离耳机、
          不要更新 APK 或重启手机、不要重复开始。
      • 
        
    • 电量要求：建议电量 ≥30% 再开始（30% 是 SDK 缺省
          低电参考值，不是设备上报阈值；设备侧升级条件 E2 会在准备/确认两轮
          再判一次，电量过低会被拒绝）。
      • 
        
    • 确认窗口：准备通过后的确认令牌 2 分钟内有效，过期
          需重新准备。
      • 
        
    • 失败处置：失败不自动重试、不自动恢复；先读状态与
          原因，不要随意放宽代码门槛或换包「试一试」。
      • 
        
    • 成功判据：版本号相同（280/0.1.1.8）不能当成功
          证据，完成后需重连确认正常连接、声音与按键行为。
