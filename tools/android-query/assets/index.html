识别身份：QCY 普通 3654:4a55 / BR28 ROM 4c4a:3442。 手机需支持 USB host（OTG）；部分手机需要「反向供电」转接头。本工具在手机上的物理链路 未实测，失败信息如实展示。
进入 ROM 模式
vendor GET_STATUS
请求83 00 fc fe · len8 能力读 → len0 一次性进入
对普通 QCY USB 身份：先能力读（须返回 8×FF），确认后只发一次进入请求——设备随即重启 重枚举，请求本身可能报协议错（-71），以重新扫描出现 BR28 UBOOT 身份为准，不重发。 若耳机应用还活着但你想主动进 ROM：保持 USB 连接状态下发送即可；完全无响应的设备只能走桌面工具流程。
只读操作
INQUIRY · FB06 · FD07 · FD05
loader = 摘要固定的 br28loader.bin（FB06 装载 0x120000 → FB08 跳转 → FC0A 校验 SPI NOR）。 ROM 窗读用 FD07 128B 分块、全片备份用 FD05 512B 扇区，均双读一致才落盘（app 私有目录）； 不一致即放弃，不自动重试。这里没有任何 Flash 写命令。
