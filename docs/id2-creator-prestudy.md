## 2. 创建者全链（post 侧 → 实为「挂链侧」）

### 2.1 节点本体：DATA 段静态初值 [静态]

特路链表节点数组 = RAM `0x12524C..0x12528C`（4 节点 × 16B）。该区间落在 DATA 段

0x125320 在数组之后），**初值来自 flash 拷贝，非 BSS 清零**。flash 源
`0x060c3338 + (0x12524C-0x124840) = 0x060c3d44`（脚本复算），dump 64B [静态]：

| 节点 | RAM 地址 | flash 字节（节选） | id(+0) | 序(+1) | 对象指针(+12) |
|---|---|---|---|---|---|
| node0 | 0x12524C | `01000000 … e0d90906` | **1** | 0x00 | 0x0609D9E0 |
| node1 | 0x12525C | `00ff0000 … fcd90906` | 0 | 0xFF | 0x0609D9FC |
| node2 | 0x12526C | `05030000 … 18da0906` | **5** | 0x03 | 0x0609DA18 |
| **node3** | **0x12527C** | `02ff0000 … 34da0906` | **2** | 0xFF | **0x0609DA34** |

（li 0x12524C 全镜像穷扫唯一命中 0x60001d8；数组内各字无其他 word 引用）[静态]。

### 2.2 挂链者：B1[0] = 0x60001b6 [静态]

0x601207e: r5 = 101462668 (=0x60C328C)   ; B1 表尾
0x6012086: r0 = [r4++=4]                  ; 逐项取函数指针
0x6012088: call r0                        ; ★B1[0] 即 0x60001b6

## 3. (20,2) 消费链全貌（含心跳重发机制）[静态]

S18 post(20,2) → 首批迭代 get-event → 特路完整链（本节全部站点已反汇编+脚本复算）：

1. filter 槽 [0x126F4C]=0 → 0x6010914 直跳子码分派（BZ 采样互证）。
2. 子码 20 → 0x6010934 call 查询 → **node3(id=2) 命中**（§2.3，无 miss 可能）。
3. 触发回调 [obj+8]=0 → **不调回调**，fall-through filter 段（r10=[0x126F4C]=0 跳过）。
4. 记账出口 0x60109fe..0x6010a10：载荷两字写
   `[0x1265C0+411*4]=[0x126C2C]`（子码 20）/`[0x126C30]`（参数 2）。
5. **注册 100-tick 心跳**：0x6010a20 `call 0x6066a0a`（尾址 0x6010a26+352228 脚本
   复算；0x6066a0a=ANCHOR 钉过的延迟投递入口）实参 (r0,r1,r2)=(0, 0x6010A3C, 100)，
   函数体 `if (r2<=3) r2=3` 后 call 0x606689a（sys_timeout_add 本体：15×36B 槽表
   @0x1261E4（0x1261E4+36×15=0x126400）找空槽/溢出 malloc，节点 {+8 回调,+12 arg,
   +30 active}——**第三套定时器**，
   不同于 sys_timer 快慢轮 0x126DF0/F8 与特路链表 0x126F3C/F44）。
6. 注册成功 → r5=0 → 特路返回 0；失败分支（r0==0）call 0x12cc40（RAM-code，AY 钉的
   N4 金丝雀域——本世界堆充足不预期触达）。
7. 回 S19 分发表 walk：20 无 handler 认领（BZ §1.5 表）→ 回 pend。
8. **100 tick 后** sys_timeout 到期 → 回调 0x6010A3C：
   ```
   0x6010a3c: [--sp]=rets
   0x6010a3e: r0 = 1207340 (=0x126C2C)   ; 记账的载荷首址
   0x6010a44: call -330 → 0x60108FE      ; 尾址 0x6010a48，脚本复算=特路入口
   0x6010a48: return
   ```
   即**把 {20,2} 重新直调特路**（不经队列、不经 S19 get-event），重走上述 1-7 并再次
   注册下一个 100-tick——**周期 1s（tick=10ms）的无限心跳**，其执行域全在纯 RAM。

对 S18 走通的含义：**(20,2) 消费链零 unmapped 停点、零 SFR 访问、零新任务/事件**；
唯一新副作用=一个 sys_timeout 定时器节点（纯 RAM 数组槽）。
