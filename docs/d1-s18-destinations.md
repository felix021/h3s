## 1. (20,2) 去向认定

### 1.1 静态链（去向已认定）[静态]

```
post 0x60123b2 → 0x6000cba(0x60a1d11,0x10000C,{20,2}) → 入队 0x6064978→0x606487c
  (slot 头 0x10000C03,载荷 {20,2})
→ S19 循环头 0x60123e6 → get-event 0x6064c8c 返 13 → 0x60123f0 消费 → 0x60123f4
  [sp]=0x10000C → bit20 0x60123f6 → 特路 0x60108fe
→ 特路按子码分派:r0=[载荷+0]=20 → 0x6010928 `r0==21` 不跳(非 21) →
  0x601092e `r0!=20` 不跳(命中 20) → 0x6010932 r0=载荷[1].b0=2 →
  0x6010934 call 0x60108c6(查 0x126F3C 链表 id=2,fallback 0x126F44)
→ 命中(id=2 节点在):0x6010980 r0=[r5+12]=[node+8] → r1=[r0+8] → 非 0 →
  0x601096a call r1(调节点回调)
```

### 1.2 运行时项（去向未认定，锚已齐待 G1）

- **id=2 节点是否存在**：0x126F3C 链表首节点 id=1、回调 0x609d9e0 [采样]，第二节点
  id 字节未采样——id=2 节点存在与否是 (20,2) 消费到「调节点回调」还是「unmapped
  诚实停」的分叉。观察器在 0x6010932（子码 20 分派）走链表实读节点 id，产出
  `d1_window.s18_destinations.id2_node.{exists,addr}`，回调命中记
  `id2_callback_seen`（锚 0x601096a）。

## 2. (18,0) 去向认定

### 2.1 静态链（去向已认定）[静态]

```
post 0x60123aa → 0x6000cba(0x60a1d11,0x10000C,{18,0}) → 入队(slot 0x10000C03,{18,0})
→ S19 循环 → get-event 13 → [sp]=0x10000C → bit20 → 特路 0x60108fe
→ 特路:r0=[载荷+0]=18 → 0x6010928 `r0==21` 不跳(非 21) → 0x601092e `r0!=20`
  跳 262(公共出口,返回 0 继续分发)
→ 表 2 walk 0x600434a/0x60252c6(不认领 18,返 0) → 表 1 walk → [39] 命中
→ handler 0x6023962:0x6023972 子码==18 → 0x60239ba call 0x60237d8(40402,0)
→ 0x60237d8 门控1:b[0x125B54](0x60237e2 读) —— 非 0 → return(短闭合);
  =0 → 0x60237ea call 0x601a590(1,40402,0)
→ 0x601a590 门控2:b[0x1265C0+2972]=b[0x12715C](0x601a59c 读) —— =0 → goto 266
  跳过深层(短闭合);非 0 → 深层 0x601a5aa…(BT/提示类,未逐层命名)
→ 返回 0 → 回环 → 空队列 pend 0x6064cf6 → K1/K2(0x601249c/0x60124ae)未执行
```

### 2.2 门控极性（本路钉死，与 BZ 表述一致）

- 门控1 `b[0x125B54]`：**非 0 → return（不进更深）**；`=0 → 查门控2`。
- 门控2 `b[0x12715C]`：**=0 → 跳过深层体（短闭合返 0）**；`非 0 → 深层体执行`。

即门控1 非 0 与门控2 =0 都是「短闭合」，两级门控极性相反。

### 2.3 运行时项（去向未认定，锚已齐待 G1）

- 门控1 b[0x125B54]=0 [采样]（→ 进入门控2 分叉）；门控2 b[0x12715C] 值未采样——
  「短闭合返 0」还是「进深层 0x601a5xx」未认定。观察器在 0x60237e2 / 0x601a59c
  两个读锚实读字节，产出 `d1_window.s18_destinations.gate1/gate2.{value,branch}`，
  并镜像进 `d1_window.d1_4.handler.gates`。

## 4. 观察器改动（d1_window_observer.py，纯观察、零新增 SFR）

- **④ 去向锚**（新常量）：`GATE1_READ_PC=0x60237e2/GATE1_ADDR=0x125B54`、
  `GATE2_READ_PC=0x601a59c/GATE2_ADDR=0x12715C`、`SPECIAL_SUBCODE20_PC=0x6010932`、
  `SPECIAL_NODE_CALLBACK_PC=0x601096a`、`ID2_LIST_HEAD=0x126F3C`/`ID2_LIST2_HEAD=0x126F44`。
  note_step 里 `_sample_s18_destination` 按锚实读 `mem.ram` 字节/走链表，产出
  `finalize` 树顶层新键 `s18_destinations`（全程口径）+ `d1_4.handler.gates` 镜像。
  值 None=未观测（未认定）、int=实读（已认定），不硬编码不猜。
- **⑤ 窗口绑定**：`_s19_loop_head_seen`（0x60123e6 首达）置位；pend 写面 0x6064cf6
  仅在 S19 循环头已见时置 `_pend_write_seen`；**删除**「窗口内新 pend 重锚」块——
  一次锚定=稳态终形，后续只有 Timer0 唤醒/repark、无新 pend 写面。

## 5. 四态纪律（不造假绿）

- D1 正式全 PASS **仍等 G1（PLED 读侧）放行**——当前前沿卡 41,847,303 @ 0x6019458
  的 JL_PLED CON3 RMW 读，S18 去向的运行时值（门控2/id=2 节点）与 park 稳态窗口
  在该放行跑之后才可真实生产。
- 本路保证的是「G1 放行后这些锚/绑定能正确生产、断言面不凑不齐」：门控/链表值
  未观测时键在值为 None（pending 语义），观测到才落 int；窗口在 S19 尚未建立时
  不开（`window_blocked_events=[]` + 无 `park` 键=pending），不把 boot 中段 park
  冒充 S19 park。
